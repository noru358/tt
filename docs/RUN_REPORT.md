# 한 판(점프 방 + 골렘) 보고 — 2026-10-09

사용자 결정: 골렘 다음은 "한 판으로 합치기". 점프맵 방 몇 개를 지나 마지막 골(G)에 닿으면 골렘 방으로 넘어가는 한 판을 만들었다.

## 실행

- Mac `RunOneRun.command`, Windows `RunOneRun.cmd`. 에디터에서는 `res://toys/run/run_toy.tscn`.
- 방 목록은 `toys/run/run.json`(기본: room_01 → room_05 → room_06). 파일만 고치면 순서와 개수가 바뀐다.

## 규칙

- 점프 구간: 움직임 장난감 그대로(승인된 `movement_tuning.json`, 가시에 죽으면 체크포인트로). 마지막 방의 골에 닿으면 골렘 방으로 넘어간다.
- 골렘 구간: 골렘 튕기기 장난감 그대로(보스전 전용 이동 수치 `boss_*`). 골렘에게 죽으면 첫 방이 아니라 골렘부터 다시.
- 이기면 결과 창에 "한 판 클리어! 총 시간 (점프 · 골렘, 몇 번째 도전)".
- 로그: 한 판마다 `user://toy_run_log.jsonl`에 한 줄(result clear/quit, 어디까지 갔는지, 총 시간, 골렘 시간, 골렘 도전 횟수). 점프 장난감과 골렘 장난감 로그도 각자 그대로 쌓인다.

## 사람이 정할 것

- **이동 수치 하나로 합칠지.** 지금은 구간마다 다르다(점프 구간은 가볍고 빠르게, 골렘 구간은 무겁게). 합쳐 해 보고 바뀌는 순간이 어색하면, 보스전 수치를 기준으로 점프 방을 다시 손보는 게 다음 일이다.
- 방 고르기와 순서. 지금 셋은 임시 선택이다.

## 검사

`RunToySuite`(12개): 목록 순서대로 방 진행, 마지막 골에서 골렘 시작, 골렘은 보스 이동 수치 사용, 골렘 사망 시 골렘부터 재시작, 승리 시 클리어 문구와 로그 한 줄, 종료 시 중복 없음.
