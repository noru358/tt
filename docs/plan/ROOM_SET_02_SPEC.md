# 방 묶음 2 — "물에 잠긴 폐사원을 오른다" (방 9~12)

## 목적

5~8번 방은 같은 패턴(구슬 일렬 + 가시 바닥)의 반복이라 방마다 기억에 남는 순간이 없다. 이번 묶음은 **방 하나에 생각 하나, 기억에 남는 순간 하나**를 원칙으로 Claude가 컨셉을 잡아 만들었다. 판정 질문은 "컨셉을 잡은 방이 반복 패턴 방보다 재밌나", 그리고 "어느 방에서 다시 해보고 싶었나"다.

새 문자·새 기능은 없다. 기존 범례(`# = . P ^ o m T G`)와 승인된 수치(`movement_tuning.json`) 그대로 쓴다.

## 설계 근거로 쓴 수치 (타일 32px 기준, 대략값)

- 일반 점프 높이 약 2.7칸, 점프 수평 거리 약 6칸.
- 공중 대시 4.7칸씩 2회. 배시·벽 점프는 공중 대시를 2회로 되돌린다.
- 배시 잡기 반경 2.25칸, 위로 배시하면 약 7칸 상승.
- 벽 점프 상승 약 4칸.

공중 대시 회복이 후해서 "닿을 수 있나"는 거의 항상 예다. 그래서 이번 묶음은 거리보다 **어디로 가면 안 되나**(천장 가시, 벽 가시, 날아오는 탄)로 긴장을 만든다.

## 방별 의도

### 9번 — 우물 (`room_09.txt`, 18×30, 세로)
- 바닥에서 시작해 4칸 폭 굴뚝을 벽 점프로 오른다. 굴뚝 안쪽 벽에 가시가 왼쪽 한 번, 오른쪽 한 번 박혀 있어 지그재그 순서를 바꿔야 한다.
- 굴뚝을 빠져나오면 탁 트인 방. 구슬 → 구슬 → 움직이는 구슬 → 왼쪽 위 목표.
- **순간**: 천장이 전부 가시다. 마지막 배시를 위로 세게 쏘면 죽고, 대각선으로 눌러 쏴야 목표 턱에 내려앉는다. "힘 조절"을 처음 요구하는 방.

### 10번 — 탄환 다리 (`room_10.txt`, 40×12, 가로)
- 30칸짜리 가시 구덩이에 구슬이 하나도 없다. 발판은 양쪽 벽 포탑이 쏘는 탄환뿐이다(오른쪽 낮게 ←, 왼쪽 높게 →).
- 점프+대시 2회로는 절반까지만 간다. 날아오는 탄을 잡아 튕겨야 건넌다.
- **순간**: 위협이던 탄이 유일한 발판이 되는 전환. 탄 간격(1.4초)에 맞춰 뛰어드는 박자 맞추기.

### 11번 — 낮은 굴 (`room_11.txt`, 50×9, 가로)
- 천장 전체가 가시, 바닥도 대부분 가시. 사이 높이는 5칸이라 일반 점프는 안전하지만 위로 배시하면 천장에 박힌다.
- 구슬 → 발판 → 움직이는 구슬 → 발판 → 구슬 → 목표.
- **순간**: 배시를 거의 수평으로만 쏘는 방. 600 속도로 낮게 쭉 미끄러지는 감각을 따로 떼어 맛보게 한다.

### 12번 — 종탑 (`room_12.txt`, 24×40, 세로, 묶음 마무리)
- 아래 굴뚝(벽 점프, 가시 지그재그) → 가운데 탄환 방(양쪽 벽 포탑 3개가 엇갈린 높이로 가로지름, 양옆에 쉬는 발판) → 위쪽 열린 하늘(구슬 2개 + 움직이는 구슬) → 가운데 작은 발판 위 목표.
- 9~11번에서 따로 배운 벽 점프·탄 튕기기·힘 조절을 한 방에서 이어 쓴다.
- **순간**: 마지막 구간은 천장 가시가 없다. 앞의 세 방 내내 위를 조심하다가 마지막에 마음껏 위로 쏘아 올라가는 해방감.

## Codex 할 일

1. `tests/MovementToySuite.gd`의 방 개수 검사(현재 8)를 12로 바꾼다.
2. 9~12번 방을 로딩 검사(경고 0건)와 경로 확인에 넣는다. 사람이 아니어도 좋으니 무적 없이 각 방 완주 가능한지 확인하고, 막히는 지점이 있으면 **어느 칸 때문인지**와 최소 수정안(구슬 한 칸 이동 등)을 보고서에 적는다. 수정은 한 칸 단위 이동까지만 하고, 방의 의도(위 "순간")를 바꾸는 수정은 하지 않고 보고만 한다.
3. 특히 확인할 것:
   - 9번: 위로 배시했을 때 천장 가시에 닿는지(닿아야 의도대로), 대각선 배시로 목표 턱에 닿는지.
   - 10번: 탄을 하나도 안 쓰고 건널 수 있으면 실패다(구덩이를 늘리거나 시작 턱을 줄이는 안을 보고).
   - 11번: 일반 점프 정점이 천장 가시에 닿지 않는지.
   - 12번: 탄환 방에서 탄을 안 쓰고 위로 대시 두 번만으로 통과되는지(되면 보고).
4. 새 기능·새 문자·수치 변경은 하지 않는다.

## 사용자 판정

- 9~12번을 5~8번과 이어서 해본다.
- 묻는 것: 컨셉 방이 더 재밌나? 가장 다시 하고 싶은 방은? 너무 어렵거나 불합리하게 죽은 곳은?
- 결과에 따라 맵 제작 방식(Claude 컨셉 + 사용자 수정 / 사용자 손그림 / 반복 생성)을 정한다.
