# 골렘 튕기기 보스 장난감 — Codex 설계서 (이틀 분량)

## 목적

움직임 장난감에서 찾은 튕기기를 보스전에 붙였을 때 재미가 생기는지 판정한다. 기존 골렘전은 "하나 잡는 건 괜찮은데 이어갈 이유가 없다"였다. 이번엔 서서 때리고 피하는 싸움이 아니라, 골렘의 공격을 발판 삼아 위로 올라가 약점을 치는 싸움을 시험한다.

판정 기준: 시키지 않았는데 다시 붙고 싶은가. 기존 골렘전(BattleArena)과 직접 비교한다.

## 범위 원칙

- 새 씬 `res://toys/golem_bash/golem_bash_toy.tscn`. 기존 BattleArena·Boss·PatternRunner·허브·장비·저장 코드는 수정하지 않는다.
- 플레이어와 이동은 움직임 장난감과 같은 구성(Player + `toy_movement_enabled` + ToyMotion + Bashable)을 그대로 재사용한다. 움직임 장난감의 현재 승인된 수치(`toys/movement/movement_tuning.json`)를 읽어서 쓴다. 이번 장난감 전용 수치는 별도 파일에 둔다.
- 골렘 그림·관절 리그는 기존 `scenes/boss/golem/GolemRig.tscn`과 부품 PNG를 재사용하되, 이 장난감 안에서는 장난감 스케일에 맞춰 축소해서 쓴다. 원본 리그·키프레임 파일은 수정하지 않는다. 필요한 동작은 장난감 쪽 스크립트에서 리그를 구동한다.
- **사용자는 F키를 쓸 수 없다.** 모든 디버그 기능은 화면 버튼·Tab/Esc·패드 Start로 접근한다. (움직임 장난감과 같은 방식)
- 사운드·새 아트·스토리 텍스트 없음.
- 수치는 전부 `res://toys/golem_bash/golem_bash_tuning.json`에 두고 튜닝 패널 슬라이더로 노출한다. 저장하면 이 파일에 기록된다.

## 아레나

방 파일 형식은 움직임 장난감 그대로 쓴다. 위치 `res://toys/golem_bash/arena.txt`. 문자 `B` 하나를 추가한다: 골렘이 서는 바닥 위치(골렘 발 중심).

- 화면은 움직임 장난감과 같은 고정 줌(800×384 기준)이며, 이 방은 한 화면보다 약간 넓어 카메라가 따라간다.
- 골렘 키는 바닥에서 약 7타일(약 220px) 기준으로 시작. 플레이어 일반 점프로는 골렘 머리 높이에 닿지 않아야 한다. 이게 핵심이다. 머리까지는 튕기기로만 간다.

## 골렘 행동

골렘은 플레이어 쪽으로 천천히 걸어오고(기존 걷기 방식 재사용 가능), 사거리 안이면 아래 세 공격 중 하나를 고른다. 각 공격은 위험하면서 동시에 튕기기 재료를 하나씩 만든다.

1. 내려찍기(slam): 텔레그래프 후 주먹을 바닥에 내리꽂는다. 충격 순간 주먹 주변 판정은 피해. 충격 후 `fist_bash_window`초 동안 주먹이 튕기기 대상이 된다(외곽선 표시). 주먹을 튕기면 플레이어는 조준 방향으로 날아가고 주먹은 아래로 밀려 골렘이 짧게 휘청인다(`fist_bash_stagger` 누적).
2. 발 구르기(stomp): 바닥을 구르면 지면을 따라 충격파가 양쪽으로 퍼지고(점프로 피함), 동시에 돌덩이 `rock_count`개가 위로 튀어 오른다. 돌덩이는 공중에서 잠깐 멈칫하다 떨어지며, 떨어지는 동안 튕기기 대상이다. 돌을 튕기면 돌은 반대 방향으로 날아가고 골렘에 맞으면 피해와 휘청임.
3. 휘두르기(sweep): 팔을 수평으로 크게 휘두른다. 휘두르는 팔 위로 넘어가거나(대시·점프) 팔을 튕겨 위로 올라탄다. 팔은 휘두르는 동안 `arm_bash_window`초만 튕기기 대상.

## 약점과 피해

- 약점은 골렘 머리 뒤쪽(등 위)의 빛나는 돌 하나. 기존 cutout 설정의 weakpoint 개념을 장난감 쪽에서 켜서 쓴다.
- 약점을 맞힐 방법: 공중에서 일반 공격, 또는 아래 공격(포고). 포고로 약점을 치면 플레이어는 위로 튀어 오르고 연속 타격이 가능하다.
- 약점 외 부위에 일반 공격은 `body_damage_mult`(기본 0.1)만 들어간다. 사실상 서서 때리는 걸로는 못 이기게 한다.
- 약점 `weak_hits_to_stagger`회 타격 또는 휘청임 누적이 임계를 넘으면 골렘이 무릎 꿇고 `kneel_duration`초 동안 머리가 낮아진다. 이때만 지상에서 약점을 때릴 수 있다.
- 골렘 체력은 짧게: 무릎 꿇리기 3번 정도면 끝나는 수준이 기본값. 길게 싸우게 만들지 않는다. 판정용이다.
- 골렘 몸통에 닿으면 기존처럼 몸박 피해. 골렘 위(머리·어깨)는 올라설 수 있는 발판으로 처리한다. 골렘 위에 올라탄 채 버티는 것도 가능해야 하고, 골렘은 일정 시간 후 몸을 털어 떨어뜨린다(`shake_off_time`).

## 화면 버튼 / 기능

움직임 장난감과 동일한 방식으로 화면 버튼 제공: 튜닝 패널, 판정 표시(골렘 피격 윤곽·약점·튕기기 범위), 무적, 게임 속도(1/0.5/0.25), 아레나 파일 다시 읽기, 골렘 리셋, 종료.

## 기록

`user://toy_golem_bash_log.jsonl`에 판마다 한 줄:
```json
{"started_at":"...","duration_sec":0,"result":"win|death|quit","deaths_before":0,"bash_count":0,"bash_by_source":{"fist":0,"rock":0,"arm":0},"weak_hits":0,"kneels":0,"retry_within_sec":null}
```
`retry_within_sec`는 끝난 뒤 다시 시작까지 걸린 초. 결과 화면에 "다시" 버튼을 두고 그걸 누르기까지의 시간을 잰다. 이게 판정 핵심 데이터다.

## 완료 조건

1. 일반 점프·대시만으로는 약점에 닿을 수 없다(자동 검사로 최대 도달 높이 < 약점 높이 확인).
2. 세 공격 각각에서 튕기기 대상이 정해진 시간 동안만 생기고, 튕겼을 때 플레이어 발사·대상 반작용·골렘 휘청임이 동작한다.
3. 튕긴 돌이 골렘에 맞으면 피해와 휘청임이 들어간다.
4. 포고로 약점 연속 타격이 된다.
5. 무릎 꿇기 → 지상 타격 가능 → 회복 순환이 동작한다.
6. 무적 OFF로 처음부터 승리까지 자동 경로 시도 결과를 보고한다. 실패하면 어디서 막혔는지 적는다. 사람 손맛 판정은 했다고 쓰지 않는다.
7. 기존 회귀 suite 전부 PASS, 움직임 장난감 suite PASS, 기존 골렘전·움직임 장난감 동작 불변.
8. 튜닝 패널 수치 변경 즉시 반영, 저장 후 재실행 유지.
9. 판마다 로그 한 줄 정확히 기록.

## 하지 않는 것

새 골렘 그림·새 키프레임 제작, 날개 보스, 장비·허브 연결, 스토리, 사운드, 요청받지 않은 리팩터링.
