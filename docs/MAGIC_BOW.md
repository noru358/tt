# 마법 활 — 2026-10-08

세 근접 무기 모두에 보조 마법 활을 추가했다. 사용자가 확정한 방향은 조준 부담 없이 자동 조준·강한 유도를 사용하고, 충전과 발사를 이동·대시에 겹치는 전투다. 점멸은 향후 업그레이드이며 이번에는 구현하지 않았다.

## 조작

- 키보드 **U**, 패드 **RB**를 누르면 충전, 떼면 발사한다. 짧게 눌러도 약한 화살을 발사한다.
- 이동·점프·지상/공중 대시 도중 충전과 발사가 가능하다. 활 자체는 이동 감속·후딜 정지를 부여하지 않는다. 공중 중력은 그대로다.
- 최대 충전 뒤에도 버튼을 놓을 때까지 유지한다. 재발사는 쿨다운 종료 후 새로 눌러야 한다. 쿨다운 중 입력을 나중에 몰아서 실행하지 않는다.
- 패리·물약·피격·사망과 메뉴/포커스/장치 전환은 충전을 취소한다. 취소 시 화살이나 쿨다운은 발생하지 않는다. 대시는 취소하지 않는다.
- 근접 공격과 별도 동작이므로 근접 연계 중에도 사용할 수 있다. 기존 근접 공격의 이동·취소 규칙은 유지한다.

## 자동 조준과 유도

캐릭터가 바라보는 방향과 무관하게 범위 내 보스를 우선 선택한다. 보스가 없으면 가까운 적/허수아비를 선택한다. 충전 중 대상 표시를 보여주고, 유효한 대상을 유지한다. 대상이 사망·삭제·무적·숨김 상태로 바뀌면 충전 중에는 다시 선택한다. 대상이 전혀 없으면 바라보는 방향으로 발사한다.

발사된 화살은 선택한 대상을 추적한다. 다른 대상으로 갑자기 갈아타지 않는다. 초당 회전량과 수명이 제한되어 끝없이 맴돌지 않는다. 적중하면 한 대상에게 한 번 피해를 주고 소멸 연출로 전환한다. 빠른 화살은 이전 위치부터 새 위치까지의 이동 선분으로 충돌을 검사해 얇은 적을 건너뛰지 않는다. 마법 화살은 현재 아레나의 플랫폼/지형에 막히지 않는다.

활의 곡선, 당겨지는 시위, 커지는 화살촉, 완충 시 금색 광륜, 발사 후 활이 흩어지는 선, 유도 궤적과 적중 파편을 도형으로 그린다. 외부 에셋·소리·플러그인은 추가하지 않았다.

## 시작 수치

모든 전투 수치는 `data/tuning/player.json`과 `data/tuning_defaults.json`, 검증 스키마에 반영했다. 기존 override는 누락 필드를 자동 보충한다. `조작감 패널 → 마법 활`에서 변경·저장할 수 있다.

| 항목 | 기본값 |
|---|---:|
| 완충 시간 | 0.8초 |
| 발사 후 쿨다운 | 1.2초 |
| 짧은 발사 / 완충 피해 | 12 / 48 |
| 짧은 발사 / 완충 속도 | 1100 / 1900 px/s |
| 유도 회전 속도 | 9 rad/s |
| 자동 조준 범위 | 2400 px |
| 화살 수명 | 1.8초 |
| 충돌 두께 | 18 px |

피해와 속도는 충전량에 따라 연속 보간한다. 장비 피해 배율과 완벽 회피 피해 버프도 반영한다. 보스의 기존 강공격 피해 기준을 넘으면 기존 스태거 규칙이 적용된다. 위 수치는 사람의 밸런스 검증을 마친 확정값이 아니라 첫 시제품 시작값이다.

## 구조

- `scripts/player/MagicBow.gd`: 이동 상태와 분리된 충전/쿨다운, 자동 표적 선택, 활·표적 표시. 플레이어가 이동을 마친 뒤 발사 위치를 읽는다.
- `scripts/combat/MagicArrow.gd`: 제한 유도, 이동 구간 충돌, 단일 적중, 궤적/충격 표현.
- `Player.gd`: 활 생성과 tick 전달, 전투/입력 경계 취소. 기존 대시·근접 공격 취소 경로는 활 충전을 지우지 않는다.
- 입력 어댑터, project.godot, 조작 안내, 패널에 U/RB와 설정을 추가했다. 결과 화면의 버튼 해제 조건에도 새 입력이 포함된다.
- 향후 점멸은 플레이어 위치만 이동시키면 충전이 유지되고 새 위치에서 발사할 수 있다. 테스트에서는 충전 중 위치 변경으로 이 경로를 확인했다. 점멸 자체는 아직 없다.

## 검증

Godot 4.6 stable macOS. 운영 저장 대신 각 실행별 fresh 경로를 사용했다.

- 전체 **687개 PASS / 실패 0**: 기존 회귀, 신규 활 40개, RegistrySuite 외부 fixture 61개 포함.
- 신규 `MagicBowSuite`는 키보드·패드 이벤트, 이동/지상·공중 대시 중 충전/발사, 반대 방향 자동 조준, 완충 유지, 이동 대상 유도, 회전 제한, 단일 적중, 쿨다운/입력 잔류, 메뉴·포커스·피격 취소, 타깃 무효화, 실제 진행 보스 피해, 세 무기 호환, 구 튜닝 저장 이전을 확인한다.
- 실제 렌더링에서도 활 전용 40개 검사와 화면 캡처를 수행했다. `docs/evidence/magic_bow/`에 로그·화면을 포함한다.
- GPU 조사: 초기 실행의 재입력 실패와 후속 실행의 발사 객체 접근 오류를 추적했다. 네이티브 창이 포커스를 잃으면 게임이 입력을 거부하는 상황을 확인했고, 합성 탭 helper가 포커스 복귀를 명시하도록 수정했다. 포커스 상실 시 충전 취소 검사는 별도로 유지한다. 최종 GPU 로그와 초기 조사 로그를 함께 보관했다.
- 실물 키보드/패드, 사용자 손맛, 게임 전체 난이도 조정은 별도다. 패드 결과는 이벤트 주입 검사다.

```sh
python3 tests/run_suites.py --godot /path/to/Godot --output /scratch/gate1-bow
```

Godot 4.6에서 `project.godot`를 열고 실행하면 허브로 진입한다. 연습 모드에서 U/RB로 바로 사용할 수 있다.
