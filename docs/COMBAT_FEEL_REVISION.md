# 전투 조작감 2차 수정 — 2026-10-07

## 원인과 변경

대시와 공격이 하나의 배타적인 상태에 묶여 대시 중 공격을 받을 수 없었다. 공격 시작 시의 방향이 표시와 판정에 고정돼 선딜 중 입력 변경도 늦게 반영됐다. 대시280은 골렘 폭360+플레이어 폭48을 통과하기에 부족했고, 일반 몸 접촉 피해15가 공격 기회를 제한했다. 이전 자동 검증은 각 동작의 단독 기능은 확인했지만 사용자가 원하는 복합 동작과 실제 회피 가능한 공간을 충분히 확인하지 못했다.

- 대시 이동 시간과 공격 진행을 분리. 대시 중 새 공격 허용, 공격 중 대시로 빠지면서 현재 타격 유지. 대시 방향은 시작 시 고정하고 공격 방향은 별도로 읽는다.
- 수평 대시 중 아래 공격 적중 시 대시는 그대로 진행한 뒤 포고 상승. 포고 적중으로 공중 대시 횟수 회복.
- 공격 선딜 중 현재 조준을 즉시 반영. 이미 활성화된 타격은 해당 방향 유지. 몸 방향, 공격 방향, 대시 방향을 별도로 처리해 공격 판정과 화살표가 어긋나지 않도록 함.
- J/패드 X 유지 시 연속 공격. 놓으면 현재 공격 후 종료. 메뉴를 열었다 닫을 때 이미 누르고 있던 공격은 자동 재개하지 않고 다시 눌러야 함.
- 흰 빈 테두리=공격 준비 범위, 채워진 영역=실제 타격, 흰 화살표=공격 방향, 청록 궤적=대시 방향, 청록 외곽=대시 무적. 화면에 입력 방향/공격 누름·뗌/동작/대시 대기시간·공중 소진/무기와 사거리 표시.
- 대시480px(기존280), 시간0.18초(0.16), 무적0.28초(0.20), 쿨다운0.30초(0.50). 모든 값은 기존 패널에서 편집 가능.
- 골렘 일반 contact_damage=0. 돌진·주먹·내려찍기·충격파·낙석의 실제 공격 피해는 유지.
- 정면/공중 공격 사거리: 검170, 대검210, 쌍단검135. 자동 전진0 유지. 무기 상세에서 각 타격별 수정 가능.
- 전투·연습 화면에 세 무기 선택 / 무기 수치 편집 / 선택·수치 저장 버튼. Step 3용 무기를 미리 써보고 설정할 수 있다. 제작/재료/성장 저장은 아직 구현하지 않음.

## 검증

새31 + 플레이어56 + 조작52 + 보스40 + 흐름17 + 데이터176 = **372/372 통과**. 별도 프로세스 저장 프로브4개 true. 정상 경로 script error 없음.

새 검사는 실제 hitbox로 검 사거리에서 보스 피해, 정면 공격 중 반대쪽 대시, 골렘 전체 폭 통과, 움직이는 돌진을 대시로 통과하여 HP 유지, 수평 대시 중 아래 타격과 포고/공중 대시 회복, 선딜 조준 반영, 모든 콤보 유지/해제, 메뉴 잔류 차단, 실제 마우스 GUI hit-testing 무기3개 선택·override 저장복원을 확인한다.

GPU 캡처 `docs/evidence/feel_dash_down.png`, `feel_weapon_select.png`를 직접 픽셀 확인. 입력은 아래+공격, 동작은 아래 타격+오른쪽 대시, 화면 판정도 아래에 표시됨을 확인. 실물 패드 조작감/최종 재미는 검증하지 않았으며 사용자 재플레이가 필요하다.

## 사용법과 범위

오른쪽으로 대시를 시작한 뒤 S+J를 누르면 오른쪽 이동을 유지하며 아래 공격. 앞을 때리는 중 A+Shift를 누르면 공격 방향을 유지하며 왼쪽으로 빠짐. 공격키 유지=연속 공격. 대시 도중 새 방향 입력은 공격 조준에 사용되고 이미 시작한 대시 궤적은 꺾지 않는다.

공격 반응/대시 탭에서 `attack_during_dash`, `dash_keeps_attack`, `attack_hold_repeat`, `pogo_resets_air_dash`를 조절한다. 이전 저장 override는 자신의 수치를 유지하므로 새 기본 거리 등을 사용하려면 해당 필드를 조절하거나 전체 기본값을 적용 후 저장한다.

Step 2 사용자 피드백 범위에서 멈춘다. Step 3 성장 루프는 미착수.
