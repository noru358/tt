# 골렘 컷아웃 이식 — 2026-10-08

## 사용자 결정과 범위

기존 골렘 공격을 **내려찍기(slam)·휩쓸기(sweep)·발구르기(stomp)** 세 패턴으로 교체한다. 제공된 리그에 없는 동작을 다른 모션으로 가장하지 않는다. 현재 골렘은 제자리에서 방향을 바꾸며 싸운다. 범용 컷아웃 제작 도구(CUTOUT_KIT_SPEC)는 다음 작업이다. 점멸도 미래 계획이며 현재는 대시만 구현한다.

이전 독립 검수 수정과 자동조준·유도 마법 활은 포함한다. 과거 문서의 6패턴 골렘 설명보다 이 보고서가 우선한다.

## 구조와 변경

- 기존 `Boss.gd → PatternRunner.gd → steps/` 실행 구조와 CombatHitbox/CombatHurtbox를 유지하고 `cutout_attack.gd` 단계를 추가했다. 별도 실험실 전투 로직을 복사하지 않았다.
- `scenes/boss/golem/GolemRig.tscn`: 원본 리그의 리소스 경로만 변경. 7개 PNG는 `assets/bosses/golem/parts/`. 노드·키프레임·뒤쪽 명암·그리기 순서 보존.
- `GolemVisual.gd`: 시각 리그, 물리 시간 샘플링, 피격 몸통 추적, 공격 판정, 착지 신호·먼지·화면 흔들림 담당. 오른쪽 원화를 루트 scale.x로만 반전하고 Linear 필터 적용.
- 기본 배율 0.7. 높이 든 주먹이 상단 HUD에 가려지던 0.85에서 조정했다. 발바닥은 기존 아레나 y=960에 맞춘다.
- `data/bosses/golem.json.cutout`에 타이밍·판정·크기·피해·AI 수치. 공장값·스키마·의미 검증도 동기화. Tab/화면 버튼의 9번째 **골렘** 탭에서 튜닝·저장한다. 선딜 변경은 이후 판정과 모션 키 시간을 함께 이동한다. 잘못된 구간 순서는 거절한다.
- 50% HP 이하: 내려찍기 선딜 0.45초, 착지 0.55초. 발구르기 착지에 좌우 충격파 발생. 단계 속도는 1.0으로 유지해 선딜 단축이 이중 적용되지 않는다.
- 기본 HP900·보상·해금·진행 구조 유지. 발밑 1.5초 체류 시 발구르기, 그 외 두 패턴 동률, 같은 패턴 3연속 금지, 대기 0.6~1.2초.
- 약점은 기본 OFF. ON일 때 공격 후 반격 구간의 앞주먹에 적용. 몸통·약점 동시 접촉은 combatant 기준으로 중복 피해 방지.
- 원본 Lab 프로젝트는 수정하지 않았다. ZIP 전체 추출물의 SHA-256 대조 및 가져온 7개 PNG/리그 경로 치환 비교 결과는 evidence에 기록한다.

`slam_heavy`, `slam_high`는 원본 리그에 보존하지만 현재 AI에서는 선택하지 않는다. 범용 제작 키트는 명세만 `docs/golem_source/`에 보존했다. 위 항목은 자동으로 다음 구현 범위에 포함되지 않는다.

## 검증 구분

Headless **744개 검사 통과**, 별도 GPU 골렘 **47개 검사 통과**. 자동검사 집계와 실행 로그는 `docs/evidence/golem/` 참조. 새 GolemCutoutSuite는 운영 골렘을 대상으로 리그, 양방향 지면 타점, 판정 구간, 실제 플레이어 피해, 중단, 타이밍 조절, 2페이즈, 패턴 선택, 제자리 AI, 약점 중복 피해, 저장·복원을 검사한다. GPU에서도 동일 테스트를 실행하고 캡처를 눈으로 확인했다.

기존 BossSuite/BattleFlowSuite/CombatFeelSuite/ReviewFixSuite는 명시적인 `tests/fixtures/legacy_golem.json`을 사용해 기존 범용 돌진·낙석 등 실행기를 회귀검증한다. 이 PASS를 새 골렘 전체 전투 검증으로 세지 않는다. RegistrySuite는 운영 컷아웃 fixture와 잘못된 타이밍/클립/배율을 별도로 검사한다.

초기 정지 자세 캡처는 순간이동 후 물리 보간 캐시 때문에 이전 자세를 표시했다. 테스트에 `reset_physics_interpolation()`을 넣어 정정했다. 실제 AI 진행 캡처에서는 강제 초기화 없이 모션 진행을 확인한다. 런타임의 물리 보간은 유지한다.

**미확인:** 사람의 장시간 전투·재미·난이도, 실물 패드, Windows/macOS 배포 바이너리, 범용 키트, 미제공 모션/효과음. 자동 입력·GPU 캡처는 사람의 손맛 검수나 실물 패드 검증을 대신하지 않는다. 이동 모션이 없어 원거리 마법 활로 쉽게 공격할 수 있는 밸런스는 후속 기획 사항이다.
