# 여행 구간 장난감 보고 (2026-10-13, Claude)

## 왜 만들었나

사용자 판단(2026-10-13): 메트로배니아식 미로 탐험은 흥미롭지만 가볍게 하기엔 너무 집중을 요구한다. 원하는 건 옛 메이플처럼 "저 너머엔 뭐가 있지"를 보러 가는 캐주얼한 탐험이다. 그래서 큰 구조 후보로 "여행형"(대체로 한 방향, 샛길은 선택, 지역이 바뀌며 넘어감, 실패 부담 적음, 이동 능력은 문 열쇠가 아니라 같은 길을 더 시원하게 지나가는 수단)을 시험한다. 질문은 하나: **미로 없이 길게 쭉 지나가는 것만으로 기분이 좋은가.**

## 실행

Mac `RunJourney.command`, Windows `RunJourney.cmd`, 에디터에서는 `toys/journey/journey_toy.tscn`. 조작은 점프 장난감과 같다.

## 무엇이 들어갔나

- 맵 `toys/journey/journey_01.txt` 한 장, 380×22칸. 문자 규칙은 점프 방과 같다(F7로 다시 읽기).
- 지역 셋(`journey.json`): 잠긴 논(계단 논·물웅덩이) → 사원 숲(뿌리 삼킨 문 둘, 나무 위 샛길, 샛길에만 총알 포대) → 바람 고개(능선 오르막, 골짜기 건너기, 전망 끝).
- 지역마다 하늘·먼 산·가까운 산·땅·풀색, 경계 14칸에 걸쳐 섞임. 시차 산 두 겹, 떠다니는 것(물빛·반딧불·꽃잎). 처음 들어설 때 지역 이름과 한 줄 배너.
- 자동 체크포인트: 두 발이 다 땅을 딛고 0.15초 서 있으면 그 자리 저장. 떨어지면 방금 밟은 땅에서 다시.
- 카메라가 바라보는 쪽으로 110px 앞서 간다(`camera_lead`).
- 디버그 글줄은 숨김(버튼 줄은 흐리게 남김). 끝에 걸린 시간·떨어짐·튕기기·지역별 시간 표시, Enter로 처음부터.
- 기록: `user://toy_journey_log.jsonl` (완주 여부, 지역별 초, 떨어짐, 튕기기, 벽 점프).
- 이동·튕기기 수치는 승인된 `movement_tuning.json` 그대로. 기존 파일은 `tests/run_suites.py`(새 검사 등록) 말고는 건드리지 않았다.

## 길 설계 의도

- 큰길은 걷고 뛰고 가끔 대시하면 지나간다. 튕기기가 꼭 필요한 곳은 바람 고개 골짜기 한 곳뿐(16칸, 구슬 셋).
- 튕기기 구슬은 대부분 웅덩이 위나 샛길 입구에 있다. 쓰면 빠르고 시원하고, 안 써도 된다.
- 사원 숲 윗길: 첫 문 앞 구슬로 지붕 → 나무 위 발판 → 구슬 사슬 → 두 번째 문 지붕 → 포대 발판(총알 튕기기). 아랫길은 조용하다.

## 확인한 것

- 단순 봇(오른쪽 누르기 + 턱·벽 앞 점프 + 빈 곳 위 대시 + 앞쪽 구슬은 오른쪽 위로 튕기기)이 무적 없이 52초, 떨어짐 0번으로 완주. 큰길이 가볍다는 근거.
- 튕기기 금지 봇은 골짜기(343칸)까지만 간다. 다른 구간은 튕기기 없이 통과.
