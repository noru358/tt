# 첫 관문 프로토타입 — Step 3

Windows에서는 GODOT_BIN 또는 PATH를 설정한 뒤 **Run.cmd**를 사용합니다. 다른 PC에서는 Godot 4.6에서 project.godot를 열어 실행 버튼을 클릭합니다. 독립 배포 파일은 Step 5 범위입니다.

## 진행

**허브 → 보스 → 보상 → 제작·장착 → 다시 도전**입니다. 골렘 처치 후 파편·핵·확률 심장으로 대검/쌍단검/갑옷/부적/반지를 제작하고 무기·방어구·부적 슬롯에 장착하세요. 재료·보유·장착·해금·처치 기록은 자동 저장됩니다. 사망해도 잃지 않습니다. 보스 목록·보상·시작 여부는 JSON에서 읽습니다. 날개 해금 후 기존 범용 실행기로 전투에 들어갈 수 있습니다. Step 4 전체 구현·검증은 별도입니다.

허브 아래 **실제 게임**은 장착 장비·보상·진행 저장을 사용합니다. **연습 모드**는 보상 없이 자유롭게 무기를 사용하며, 안에서 골렘 연습에도 들어갈 수 있습니다. 각 모드의 화면 버튼/일시정지/전투 결과에서 **허브로 돌아가기**를 누르세요.

**연습 모드**에서는 모든 무기를 미리 선택·편집할 수 있습니다. 진행 전투에는 허브에서 장착한 무기가 적용됩니다. 조작감·무기 수치를 지속하려면 별도로 **전체 저장 / 선택·수치 저장**을 누르세요. 진행 저장과 튜닝 저장은 별개입니다.

## 조작

- 이동/방향: WASD 또는 방향키 / 패드 스틱·D-pad
- 점프: Space / A
- 8방향 대시: 방향 + Shift / B
- 공격: J / X. 지상 4타 콤보(횡베기 → 되베기 → 찌르기 → 마무리), 유지 또는 연타로 연결. W/S로 위/공중 아래 공격.
- 패리: K / LB. 공격 중 즉시 전환하며 대시와 동시에 사용 가능.
- 포션: L / Y
- 패널·일시정지: 화면 버튼 / Tab / Esc / Start
- 재시작: R / 사망·승리 후 패드 A / 화면 버튼
- 허브: 마우스 또는 방향키·Enter / 패드 방향·A

**F키는 사용하지 않습니다.** 공격 중 대시로 빠질 수 있고, 수평 대시 도중 S+J를 입력해도 대시 궤적은 유지하며 아래를 공격합니다. 1~4타는 청록/보라/분홍/금색 궤적으로 구별하며 머리 위 타수·4개 점이 진행을 표시합니다. 마지막 타격은 굵은 이중 궤적과 FINISH 표시가 나옵니다. 청록 외곽은 대시 무적입니다. 대시·패리를 누르면 성공/쿨다운/공중 횟수 소진 등의 이유를 표시합니다. 쿨다운 종료 직전 입력은 최대0.10초만 보존합니다. 피격 중 방어 취소는 패널에서 조절합니다.

빠른 공격 탭은 기본 0.18초 동안 다음 한 타만 예약합니다. 키를 떼어도 유효시간 내 한 번만 이어지고, 게임 시간 만료·패리 취소·포커스/메뉴 전환에서는 정리됩니다. 패널의 **공격 예약 수명 / 키를 떼면 연계 예약 삭제**로 변경할 수 있습니다. 헛패리 후딜은 기본적으로 이동·공격·점프·대시를 막으며 성공한 패리만 즉시 반격합니다. 패널에서 헛패리 취소 옵션을 바꿀 수 있습니다. 지상 대시 도중 새 점프를 누르면 대시를 끊고 점프합니다. 짧은 방향 조합은 누른 순간의 방향을 사용합니다.

화면의 **키 수신 누계**는 J/K/Shift/Space 동작 입력이 게임에 들어온 횟수입니다. 버튼을 눌렀을 때 숫자가 오르는지와 바로 위 쿨다운/공중 횟수 안내를 함께 확인할 수 있습니다.

## 저장·검증

기본값: 공격 중 이동0.4배, 일반 타격 히트스톱0.05초, 지상 콤보 전진30px, 대시300px/무적0.20초/쿨다운0.45초. 유지·연타는 같은 chain_at 시점부터 연계합니다. 모두 패널에서 변경·저장할 수 있습니다.

진행: user://save.json. 직전 .bak 및 명시적 초기화 시 별도 reset 백업. 데이터 추가·삭제에 맞게 저장을 이전하며 변경 전 .pre-migrate.bak을 남깁니다. 디버그 사용 전투는 보상·처치를 지급하고 최고 시간은 제외합니다. 저장 오류는 화면에 표시하며 손상 파일을 자동 초기화하지 않습니다. 초기화 버튼은 허브와 디버그 패널에 있습니다.

JSON 검증 실패 시 전투 진입을 막고 오류 화면을 표시합니다. 테스트는 사용자 진행 파일과 별도 경로를 사용했습니다. 567개 자동 검사, 새 프로세스 진행 복원, 튜닝 저장4프로브, GPU 화면 확인을 통과했습니다. 실물 키보드/패드 조작감과 재미는 직접 확인이 필요합니다.
